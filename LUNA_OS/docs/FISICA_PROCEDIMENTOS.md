## 1. CABELO - FLUXO COMPLETO

### 1.1 Escova Simples

```
┌─────────────────────────────────────────────────────────────┐
│ FASE 1: LAVATÓRIO                                           │
│ - Tempo: 15-20 min                                          │
│ - Profissional: Auxiliar ou própria escovista               │
│ - Cliente: Deitada, molhada                                 │
│ - Pós: Tocar cabelo molhado                               │
└─────────────────────────────────────────────────────────────┘
                            ↓
                    [JANELA: 0 min]
                            ↓
┌─────────────────────────────────────────────────────────────┐
│ FASE 2: SECAGEM + ESCOVA                                    │
│ - Tempo: 30-40 min                                          │
│ - Profissional: Escovista                                   │
│ - Cliente: Sentada, movimento mínimo                        │
│ - Pós: Pode fazer unha AGORA                               │
└─────────────────────────────────────────────────────────────┘
                            ↓
                    [FINALIZADO]
```

**Tempo Total:** 45-60 min  
**Pode fazer junto:** Unhas (mãos) durante secagem/escova  
**Não pode:** Maquiagem (cliente move cabeça)

```
┌─────────────────────────────────────────────────────────────┐
```

```
│ - Tempo: 40 min                                             │
│ - Profissional: Manicure                                    │
│ - Cliente: Sentada, mãos imóveis                            │
│ - Mobilidade: Manicure vai até cliente (cadeira com roda)   │
```

**Tempo Total:** 40 min  
**Pode fazer junto:**

## 3. MAQUIAGEM - FLUXO COMPLETO

### 3.1 Make Casual / Básica

```
┌─────────────────────────────────────────────────────────────┐
│ PRÉ-REQUISITOS OBRIGATÓRIOS:                                │
│ 1. Cabelo JÁ FINALIZADO (escova/penteado pronto)            │
│ 2. Unhas JÁ FEITAS (ou pelo menos secas)                    │
│ 3. Cliente ESTÁVEL na cadeira                               │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│ FASE ÚNICA: APLICAÇÃO MAKE                                  │
│ - Tempo: 40-60 min                                          │
│ - Profissional: Maquiadora                                  │
│ - Cliente: Sentada, IMÓVEL, cabeça estável                  │
│ - Pós: PRONTA PARA EVENTO                                  │
└─────────────────────────────────────────────────────────────┘
```

**Tempo Total:** 40-60 min  
**POR QUE SEMPRE POR ÚLTIMO:**
1. Cabeleleira mexe com cabelo → estraga make
2. Calor de secador/chapinha → derrete make
3. Spray de cabelo → cai no rosto
4. Cliente precisa estar imóvel → depois de unhas prontas

**Nunca fazer junto com:**
- ❌ Lavatório (posição)
- ❌ Secagem (calor + movimento)
- ❌ Chapinha (calor direto)
- ❌ Unhas (cliente move mãos/cabeça)

## 5. MATRIZ DE COMPATIBILIDADE

### O Que Pode Fazer JUNTO (mesmo horário):

| Serviço 1 | Serviço 2 | Compatível? | Condição |
|-----------|-----------|-------------|----------|
| Progressiva (pausa) | Manicure | ✅ SIM | Pausa >40 min |
| Progressiva (pausa) | Pedicure | ✅ SIM | Pausa >60 min |
| Tintura (pausa) | Manicure (mãos) | ✅ SIM | Pausa >30 min |
| Tintura (pausa) | Pedicure | ❌ NÃO | Cliente não move pés |
| Escova (secagem) | Manicure | ✅ SIM | Durante secagem |
| Escova (secagem) | Pedicure | ⚠️ DEPENDE | Acesso aos pés |
| Penteado | Manicure | ⚠️ DEPENDE | Se não mover mãos |
| Penteado | Pedicure | ✅ SIM | Se cadeira permitir |
| Make | NADA | ❌ NUNCA | Sempre por último |
| Lavatório | NADA | ❌ NUNCA | Mãos ocupadas |

### O Que NUNCA Pode Fazer Junto:

| Combinação | Razão |
|------------|-------|
| Make + Qualquer coisa | Cliente precisa estar imóvel |
| Lavatório + Unhas | Mãos molham |
| Chapinha + Make | Calor derrete make |
| Tintura + Pedicure | Cliente não pode mover pés |
| Progressiva (fase 1 ou 3) + Make | Calor + movimento |

## 7. REGRAS DE OURO PARA A LUNA

### Regra 1: SEMPRE perguntar sobre simultaneidade
```
"Você tem preferência por alguma profissional?
Se não tiver, consigo organizar com duas profissionais
e você sai bem mais rápido!"
```

### Regra 2: Identificar JANELAS de oportunidade
```python
if servico == "progressiva":
    janela_disponivel = pausa_quimica  # 40-90 min
    if janela_disponivel >= 40:
        sugerir("manicure_durante_pausa")
```

### Regra 3: NUNCA prometer make antes do cabelo
```python
if cliente_quer("make") and not cabelo_finalizado:
    explicar("Make é sempre por último porque...")
    agendar(make, depois=cabelo_pronto)
```

### Regra 4: Verificar DISPONIBILIDADE de profissionais
```python
if escovista_disponivel and manicure_disponivel:
    # Otimizar tempo
    agendar_em_paralelo(escova, unhas)
else:
    # Sequencial
    agendar_em_sequencia(escova, unhas)
```

### Regra 5: Considerar TEMPO DE SECAGEM/CURA
```python
if servico == "gel":
    tempo_total += cura_uv  # 2-3 min por camada
    cliente_nao_pode_mover("maos")
```

## 8. SCRIPTS PARA A LUNA

### Quando cliente quer múltiplos serviços:

```
"Perfeito! Para otimizar seu tempo, podemos fazer assim:

1. Começamos lavando seu cabelo (20 min)
2. Enquanto o produto age, fazemos suas unhas (40 min)
3. Finalizamos o cabelo (30 min)
4. Terminamos com a make (40 min)

Assim você fica pronta em 2h30 em vez de 3h30!
Tem preferência por alguma profissional?"
```

### Quando NÃO dá para fazer junto:

```
"Entendi! Nesse caso, não conseguimos fazer [serviço 1] 
junto com [serviço 2] porque [razão física: calor/água/movimento].

O ideal é fazermos em sequência:
1. [Serviço 1] - X minutos
2. [Serviço 2] - Y minutos

Total: Z minutos. Quer agendar assim?"
```

### Quando cliente insiste em ordem errada:

```
"Entendo que você prefira fazer [ordem da cliente], 
mas preciso te alertar que [consequência física: 
a make vai derreter / o gel vai estragar / etc.].

Para garantir o melhor resultado, recomendamos:
[ordem correta baseada na física]

Podemos seguir assim?"
```
