## 🎯 REGRAS DE OURO

### Regra 1: MAQUIAGEM SEMPRE POR ÚLTIMO
**Razão:** Cliente precisa estar imóvel, sem calor ou água
```
Nunca fazer make durante:
- Lavatório (posição)
- Secagem (calor + movimento)
- Chapinha (calor direto)
- Unhas (cliente move mãos/cabeça)
```

### Regra 2: LAVATÓRIO MOLHA MÃOS
```
Nunca fazer unhas antes ou durante lavatório
Mãos molham → esmalte estraga
```

### Regra 3: JANELAS DE OPORTUNIDADE
```
Progressiva (pausa 40-90 min) → Manicure + Pedicure
Tintura (pausa 30-40 min) → Manicure (mãos)
Escova (secagem 20 min) → Manicure (início)
```

### Regra 4: CALOR ESTRAGA MAKE
```
Chapinha/secador derretem maquiagem
Sempre finalizar cabelo ANTES da make
```

### Regra 5: PERGUNTA OBRIGATÓRIA DE REMOÇÃO
```
Sempre perguntar antes de manicure/gel:
"Você está com gel ou alongamento nas mãos ou nos pés?"
Remoção: R$ 30, 30 minutos
```
