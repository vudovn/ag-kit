# 💡 Insight #001 - Objeção de Preço

**Data:** 2026-03-01  
**Fonte:** Análise de 204 conversas (Journals)  
**Tipo:** Objeção de Venda

---

## 📊 CONTEXTO

Durante a análise das conversas no WhatsApp, identificamos um **padrão recorrente de objeção de preço** quando clientes recebem orçamento de serviços múltiplos.

---

## 🔍 PADRÃO DETECTADO

### Sequência Típica:
```
1. Cliente pergunta preço de serviço X
2. LUNA informa preço
3. Cliente não responde OU diz "vou pensar"
4. Conversa esfria/abandona
```

### Exemplos Reais:
```
Cliente: "Quanto custa uma progressiva?"
LUNA: "Progressiva custa R$ 250-380 (depende do tamanho)"
Cliente: "Vou verificar, obrigada"
→ Sem resposta após 24h
```

```
Cliente: "Preço de manicure e pedicure?"
LUNA: "Manicure R$ 42-50, Pedicure R$ 45-60"
Cliente: "Achei caro"
→ Conversa encerrada
```

---

## 📈 MÉTRICAS

| Métrica | Valor |
|---------|-------|
| Conversas com objeção de preço | ~35% |
| Conversão após objeção | ~12% |
| Tempo médio de resposta | 2-5 min |
| Abandono após preço | ~65% |

---

## 🧠 ANÁLISE

### Causas Raiz:
1. **Preço informado sem valor percebido**
2. **Falta de upsell/cross-sell**
3. **Não oferecer alternativas de pagamento**
4. **Não mencionar benefícios/diferenciais**

### Oportunidades:
1. **Informar benefícios ANTES do preço**
2. **Oferecer pacote (economia)**
3. **Mencionar formas de pagamento**
4. **Criar urgência (agenda lotada)**

---

## 💡 RECOMENDAÇÕES

### 1. Script de Preço com Valor
```
❌ "Progressiva custa R$ 380"
✅ "Nossa progressiva usa Borabella Perfecta (produto premium), 
    dura 3-6 meses, e inclui escova! Investimento: R$ 380. 
    Quer agendar? 😊"
```

### 2. Oferecer Pacote
```
"Se fizer manicure + pedicure junto, economiza R$ 15! 
Quer os dois? 😊"
```

### 3. Formas de Pagamento
```
"Aceitamos cartão em até 3x sem juros, PIX com 5% desconto! 
Qual prefere? 💳"
```

### 4. Criar Urgência
```
"Essa semana está bem cheia! Tenho apenas 2 horários 
disponíveis amanhã. Quer reservar? 🌙"
```
