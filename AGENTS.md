# Project Agent Guide

This repository is an isolated project under `01-projects/`.

## Read First

1. `README.md`
2. `AGENT_FLOW.md`
3. Project-specific docs under `.agent/` and `.github/`

## Working Rules

- Keep changes scoped to this repository only.
- Do not change workspace-level governance from inside this project.
- Preserve existing behavior unless the task explicitly requests changes.
- Prefer small, atomic commits on feature branches.

## Validation

- Run project validation commands before proposing merges.
- If validation cannot run locally, report that explicitly.
